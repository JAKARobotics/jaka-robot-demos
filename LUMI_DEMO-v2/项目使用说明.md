# LUMI 大模型移动分拣机器人应用

## 项目简介

本项目基于视觉大模型与机器人集成，面向**多站点移动分拣**场景，区别于传统的原地固定位置视觉抓取。系统支持：

- ✅ **多站点任务调度**：机器人可移动到不同站点执行分拣任务
- ✅ **AGV联动**：支持与AGV（自动导引车）协同作业，实现移动式分拣
- ✅ **外部轴控制**：支持机器人安装在外部轴上，扩大工作范围
- ✅ **智能任务分配**：根据站点配置和操作模式自动调度任务
- ✅ **手眼标定**：支持多站点标定，确保各站点抓取精度
- ✅ **视觉识别与抓取**：基于阿里云视觉大模型的物体检测与抓取

**核心特点**：本项目不是原地固定位置的视觉抓取，而是支持**移动式多站点分拣**的完整解决方案。

---

## 目录结构

- `multi_station_demo.py` 多站点分拣主控脚本
- `visualDetect_ali.py` 视觉识别与抓取主流程
- `visualValidCalib.py` 标定结果验证与像素-世界坐标映射
- `AutoCalibProccess.py` 手动手眼标定采集与计算
- `utilfs/` 机器人与工具函数库
- `conf/` 配置文件（机器人参数、标定参数、站点配置等）
- `requirements.txt` 依赖环境
- `JAKA_SDK_LINUX/` JAKA机器人SDK（需配置环境变量）
- `images/` 检测结果与采集图片保存目录

## 环境配置

1. **依赖安装**
   ```bash
   pip install -r requirements.txt
   ```
   - 依赖主要包括：`opencv-python`, `numpy`, `matplotlib`, `dashscope` 等。

2. **Orbbec相机SDK**
   - 推荐使用 [pyorbbecsdk](https://github.com/orbbec/pyorbbecsdk) 或本项目自带的 `OrbbecSDK` 目录。
   - 确保相机驱动和SDK已正确安装。

3. **JAKA机器人SDK**
   - 将 `JAKA_SDK_LINUX` 路径加入环境变量：
     ```bash
     export LD_LIBRARY_PATH=/path/to/JAKA_SDK_LINUX:$LD_LIBRARY_PATH
     ```

## 配置文件说明

### `conf/userCmdControl.json`

- **cameraParams**：相机对齐、同步、图片保存路径
- **objects**：分拣目标与放置目标名称
- **operationMode**：操作模式（`both`/`grasp_only`/`put_only`/`grasp_priority`）
- **robotParams**：机器人初始位姿、抓取/放置偏移、抬升高度等
- **calibrateParams**：标定板参数、机器人IP、标定图片保存路径
- **genNearPointParams**：像素点深度搜索参数
- **systemConfig**：机器人、AGV、外部轴等系统IP与端口
- **stations**：多站点配置（站点名、AGV标记、机器人/外部轴初始位、站点操作模式）

### `conf/CalibParams-lumi-hand.json`

- 相机内参、畸变、旋转、平移矩阵（标定结果）

## 主要功能与脚本

### 1. 多站点分拣任务（`multi_station_demo.py`）⭐ **核心功能**

- **移动式分拣**：支持机器人移动到多个站点执行分拣任务，而非固定在单一位置
- **AGV协同**：与AGV联动，实现机器人随AGV移动到不同站点
- **外部轴支持**：支持机器人安装在外部轴上，扩大工作范围
- **智能调度**：根据站点配置和操作模式自动调度任务流程
- **站点配置**：每个站点可独立配置AGV标记、机器人初始位姿、操作模式等
- 运行方式：
  ```bash
  python multi_station_demo.py
  ```

### 2. 视觉检测与抓取（`visualDetect_ali.py`）

- **单站点模式**：可在指定站点执行视觉识别与抓取任务
- 支持自动/手动两种模式，自动识别目标物体与放置点，自动完成抓取与放置动作
- 支持命令行参数：
  - `--auto` 自动执行（不等待人工确认）
  - `--camera-sn` 指定相机序列号
  - `--list-cameras` 列出所有可用相机
- **注意**：此脚本主要用于单站点测试，多站点场景请使用 `multi_station_demo.py`
- 运行方式：
  ```bash
  python visualDetect_ali.py --auto
  ```

### 3. 手动手眼标定（`AutoCalibProccess.py`）

- 按 `k` 采集一组图片与机器人位姿，按 `p` 执行标定计算，按 `q` 退出。
- 标定结果保存在 `conf/CalibParams-lumi-hand.json`。

### 4. 标定结果验证（`visualValidCalib.py`）

- 实时显示相机画面，点击像素点可输出其世界坐标，辅助验证标定精度。

## 典型流程

### 多站点分拣流程

1. **手眼标定**  
   运行 `AutoCalibProccess.py`，在各站点采集标定图片与位姿，生成标定参数。
   - **多站点标定**：需要在每个站点分别进行标定，确保各站点抓取精度

2. **标定验证**  
   运行 `visualValidCalib.py`，点击画面验证像素-世界坐标映射。

3. **配置参数**  
   编辑 `conf/userCmdControl.json`，设定：
   - **系统配置**：机器人、AGV、外部轴等IP与端口
   - **站点配置**：各站点的AGV标记、机器人初始位姿、操作模式
   - **目标物体**：待抓取物体与放置位置名称
   - **机器人参数**：抓取/放置偏移、抬升高度等

4. **多站点分拣任务运行**  
   运行 `multi_station_demo.py`，系统将：
   - 根据站点配置自动调度任务
   - 控制AGV移动到目标站点
   - 在站点执行视觉检测与抓取
   - 完成后移动到下一个站点
   - 循环执行直到所有站点任务完成

### 单站点测试流程

如需在单个站点测试视觉抓取功能，可运行：
```bash
python visualDetect_ali.py --auto
```
**注意**：此模式仅用于单站点功能测试，不涉及AGV移动和多站点调度。

## 注意事项

### 多站点分拣注意事项

- **硬件配置**：需提前配置好机器人、相机、AGV、外部轴等硬件网络与SDK环境
- **站点标定**：每个站点都需要单独进行手眼标定，标定参数需与实际相机/机器人安装位置一致
- **AGV通信**：确保AGV通信协议正确配置，能够接收移动指令
- **站点配置**：运行前请确保 `conf/userCmdControl.json` 中站点配置正确
  - 站点名称、AGV标记需与实际一致
  - 机器人初始位姿需确保在各站点可达
  - 操作模式需根据实际需求配置
- **路径规划**：确保AGV移动路径无障碍，机器人工作空间覆盖各站点

### 与原地抓取的区别

| 特性 | 原地固定抓取 | 本项目（多站点移动分拣） |
|------|------------|----------------------|
| 工作范围 | 单一固定位置 | 多个站点，可移动 |
| AGV支持 | 不支持 | ✅ 支持AGV联动 |
| 外部轴 | 不支持 | ✅ 支持外部轴扩展 |
| 任务调度 | 单一任务循环 | ✅ 多站点智能调度 |
| 应用场景 | 固定工位分拣 | 移动式多站点分拣 |

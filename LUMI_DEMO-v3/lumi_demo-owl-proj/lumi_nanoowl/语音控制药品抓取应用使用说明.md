# 语音唤醒系统 (Voice Wakeup System)

基于语音识别、目标检测、机器人控制等技术的智能语音交互系统，支持语音唤醒、命令识别、任务执行等功能。

## 系统架构

### 核心组件

- **语音识别服务** (`services/voice_recognition_service.py`) - 基于 Whisper 的语音识别
- **语音合成服务** (`services/voice_synthesis_service.py`) - 支持讯飞 TTS 和 MeloTTS 两种方案
- **二维码扫描服务** (`services/qr_scan_service.py`) - 基于 Orbbec 相机的二维码识别
- **目标检测服务** (`services/object_detection_service.py`) - 基于 Owl 的目标检测
- **AGV 控制服务** (`services/agv_control_service.py`) - AGV 移动控制
- **机器人控制服务** (`services/robot_control_service.py`) - 机械臂控制

### 系统层次

```
start_voice_wakeup_system.py (启动脚本/入口)
    ↓
voice_wakeup_system.py (核心系统/主控制器)
    ↓
各个服务模块 (VoiceRecognitionService, VoiceSynthesisService 等)
    ↓
底层实现 (QR_SCAN.py, multi_camera_manager.py 等)
```

## 功能特性

### 语音交互
- **语音唤醒**: 支持自定义唤醒词（默认："lumi"）
- **命令识别**: 实时语音命令识别和解析
- **语音反馈**: TTS 语音合成回复，支持两种方案：
  - **讯飞 TTS**：在线服务，需要 API 密钥，音质稳定
  - **MeloTTS**：本地离线方案，无需 API，支持多语言，可在 CPU 上实时推理

### 视觉感知
- **二维码扫描**: 自动识别和解析二维码内容
- **目标检测**: 基于 Owl 模型的目标检测和定位
- **多相机支持**: 支持多个 Orbbec 相机同时工作

### 任务执行
- **AGV 导航**: 自动移动到指定位置
- **机械臂控制**: 目标抓取和操作
- **任务编排**: 复杂任务的自动化执行

## 快速开始

### 环境要求

- Python 3.8+
- Orbbec 相机 (Gemini 2 L)
- **TTS 方案选择**：
  - **方案一（讯飞 TTS）**：需要讯飞 TTS API 密钥
  - **方案二（MeloTTS）**：无需 API，本地运行，支持 GPU/CPU
- AGV 和机械臂硬件

### 安装依赖

```bash
pip install -r requirements.txt
```

### 配置设置

1. **音频设备配置**
   - 确保输入设备（麦克风）和输出设备（扬声器）正确连接
   - 在 `audio_tool/audio_tools.py` 中配置设备名称

2. **相机配置**
   - 连接 Orbbec 相机
   - 在配置文件中设置相机序列号

3. **TTS 配置（二选一）**
   
   **方案一：讯飞 TTS（在线服务）**
   - 配置讯飞 TTS 的 APPID、APIKey、APISecret
   - 优点：音质稳定，无需本地模型
   - 缺点：需要网络连接和 API 密钥
   
   **方案二：MeloTTS（本地离线）**
   ```bash
   # 安装 MeloTTS
   cd MeloTTS
   pip install -e .
   
   # 或使用 pip 直接安装
   pip install melotts
   ```
   - 优点：无需 API，离线运行，支持多语言，可在 CPU 上实时推理
   - 缺点：首次使用需要下载模型（约几百MB）
   - 支持语言：中文（ZH）、英文（EN-US/EN-BR/EN-AU/EN-INDIA）、日语（JP）、韩语（KR）、西班牙语（ES）、法语（FR）
   - 使用示例：
     ```python
     from melo.api import TTS
     model = TTS(language='ZH', device='auto')  # auto 自动选择 GPU/CPU
     speaker_ids = model.hps.data.spk2id
     model.tts_to_file("你好，我是机器人", speaker_ids['ZH'], 'output.wav', speed=1.2)
     ```

4. **API 配置**
   - 配置 AGV 和机械臂的 IP 地址

### 启动系统

#### 1. 完整系统启动
```bash
python3 start_voice_wakeup_system.py --mode full
```

#### 2. 仅启动 Owl 检测服务
```bash
python3 start_voice_wakeup_system.py --mode owl
```

#### 3. 测试各个服务
```bash
python3 start_voice_wakeup_system.py --mode test
```

## 使用说明

### 语音交互流程

1. **唤醒系统**: 说出唤醒词 "lumi"
2. **等待确认**: 系统回复 "您好，我在"
3. **发出命令**: 说出具体指令
4. **执行任务**: 系统自动执行相应任务

### 支持的命令

- `"请帮我根据桌上的盒子拿药"` - 执行拿药任务
- `"停止"` 或 `"退出"` - 退出当前任务，等待下次唤醒

### 拿药任务流程

1. 语音确认任务
2. AGV 移动到桌子位置
3. 扫描二维码获取药品信息
4. AGV 移动到货架位置
5. 目标检测和机械臂抓取
6. 返回桌子，任务完成

## 服务模块详解

### 语音识别服务
- **功能**: 实时语音识别，支持唤醒词检测和命令识别
- **配置**: 唤醒词、录音时长、识别间隔等
- **使用**: 支持同步和异步识别模式

### 语音合成服务
- **功能**: 文字转语音，支持指定输出设备
- **配置**: 
  - **讯飞 TTS**：APPID、APIKey、APISecret、输出设备名称
  - **MeloTTS**：语言代码（language）、设备（device: 'auto'/'cuda'/'cpu'）、说话人ID（speaker_id）、语速（speed）
- **特性**: 
  - 自动重采样到 44100Hz，支持队列播放
  - MeloTTS 支持中英文混合，支持多语言切换
  - 两种方案可通过配置文件切换
- **切换方法**：
  - 在 `conf/voice_wakeup_config.json` 中设置 `tts_provider: "xfyun"` 或 `"melotts"`
  - 使用 MeloTTS 时，配置示例：
    ```json
    {
      "voice_synthesis": {
        "provider": "melotts",
        "language": "ZH",
        "device": "auto",
        "speaker_id": "ZH",
        "speed": 1.2,
        "output_device_name": "USB Audio Device",
        "volume": 1.0
      }
    }
    ```

### 二维码扫描服务
- **功能**: 基于相机的二维码识别
- **配置**: 相机序列号、保存目录
- **特性**: 支持只使用彩色图像，不依赖深度数据

### 目标检测服务
- **功能**: 基于 Owl 模型的目标检测
- **配置**: 相机序列号、Web 服务地址
- **特性**: 支持多目标检测和抓取规划

## 开发指南

### 添加新服务

1. 在 `services/` 目录下创建新的服务类
2. 实现标准的服务接口（start, stop, 等）
3. 在 `voice_wakeup_system.py` 中集成新服务

### 扩展命令处理

1. 在 `_handle_command` 方法中添加新的命令解析逻辑
2. 实现对应的任务执行方法
3. 更新语音提示和错误处理

### 相机配置

- **多相机支持**: 通过 `multi_camera_manager.py` 管理多个相机
- **设备选择**: 支持按序列号或索引选择相机
- **深度数据**: 可选择是否需要深度数据（二维码扫描只需彩色图像）

## 故障排除

### 常见问题

1. **音频设备未识别**
   - 检查设备连接和权限
   - 运行 `python3 audio_tool/test_audio_devices.py` 检查设备

2. **相机初始化失败**
   - 检查 USB 连接和驱动
   - 运行 `python3 multi_camera_manager.py` 检查设备状态
   - 确认 udev 规则已正确安装

3. **语音识别不准确**
   - 检查麦克风音量和环境噪音
   - 调整录音参数和识别间隔

4. **TTS 播放失败**
   - **讯飞 TTS**：
     - 检查讯飞 API 配置（APPID、APIKey、APISecret）
     - 检查网络连接
   - **MeloTTS**：
     - 确认已安装 MeloTTS：`pip install melotts`
     - 首次使用会自动下载模型，确保网络畅通
     - 检查设备配置（GPU/CPU）
     - 运行测试：`python3 MeloTTS/test_melotts.py`
   - 确认输出设备正确配置

### 调试工具

- `diagnose_devices.py` - 设备诊断和修复
- `test_audio_devices.py` - 音频设备测试
- `multi_camera_manager.py` - 相机设备管理
- `MeloTTS/test_melotts.py` - MeloTTS 功能测试
- `tts_kokoro_test.py` - Kokoro TTS 测试（可选，未集成到主服务）

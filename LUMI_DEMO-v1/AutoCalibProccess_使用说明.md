# AutoCalibProccess.py 使用说明

## 功能简介

`AutoCalibProccess.py` 是一个用于机器人手眼标定的自动化程序。它通过采集多组标定板图像和对应的机器人TCP位姿数据，自动完成相机到机器人基坐标系的外参标定。

## 主要功能

- ✅ 交互式数据采集（按键控制）
- ✅ 自动检测标定板角点
- ✅ 自动保存标定图像和机器人位姿
- ✅ 基于项目名称的文件管理
- ✅ 自动执行手眼标定计算
- ✅ 保存标定结果到配置文件

## 环境要求

### 硬件要求
- JAKA 机器人（已连接并配置IP）
- Orbbec 3D相机（已连接）
- 标定板（棋盘格）

### 软件要求
- Python 3.10+
- 已安装以下依赖：
  - `opencv-python`
  - `numpy`
  - `getch` (用于按键输入)
  - `pyorbbecsdk` (Orbbec SDK)
  - JAKA SDK

## 配置文件说明

### 配置文件位置
`conf/userCmdControl.json`

### 关键配置项

```json
{
  "calibrateParams": {
    "projectName": "project1",              // 项目名称（必填）
    "robotIP": "192.168.10.90",            // 机器人IP地址
    "boardRowNums": 8,                      // 标定板行数（内角点数）
    "boardCowNums": 11,                     // 标定板列数（内角点数）
    "boardLength": 10                       // 标定板方格边长（单位：mm）
  }
}
```

### 配置项说明

| 配置项 | 说明 | 示例值 |
|--------|------|--------|
| `projectName` | 项目名称，用于创建项目目录和文件命名 | `"project1"` |
| `robotIP` | 机器人控制器IP地址 | `"192.168.10.90"` |
| `boardRowNums` | 标定板内角点行数（垂直方向） | `8` |
| `boardCowNums` | 标定板内角点列数（水平方向） | `11` |
| `boardLength` | 标定板每个方格的边长（毫米） | `10` |

**注意：** 
- `boardRowNums` 和 `boardCowNums` 是**内角点**的数量，不是方格数
- 例如：8x11的棋盘格有 8行×11列 = 88个内角点

## 使用步骤

### 1. 准备工作

#### 1.1 检查环境变量
确保已设置 Orbbec SDK 相关环境（如果需要）

#### 1.2 配置机器人IP
在 `conf/userCmdControl.json` 中设置正确的机器人IP地址

#### 1.3 配置标定板参数
根据实际使用的标定板，设置：
- `boardRowNums`: 内角点行数
- `boardCowNums`: 内角点列数  
- `boardLength`: 方格边长（mm）

#### 1.4 设置项目名称
在配置文件中设置 `projectName`，例如：
```json
"projectName": "hand_eye_calib_v1"
```

### 2. 运行程序

```bash
cd LUMI_DEMO-v1
python AutoCalibProccess.py
```

### 3. 数据采集流程

程序启动后会显示：
```
当前项目名称: project1
项目目录: /path/to/calibrate_projects/project1
标定图像保存目录: /path/to/calibrate_projects/project1/images
机器人位姿保存路径: /path/to/calibrate_projects/project1/project1_robotTcpPos.txt
标定结果保存路径: /path/to/calibrate_projects/project1/conf/project1_CalibParams.json

--------------请按下k进行数据采集-------
--------------请按下p开始标定-------
--------------请按下q退出程序-------
```

#### 按键说明

| 按键 | 功能 | 说明 |
|------|------|------|
| **k** | 采集数据 | 采集当前机器人位姿和标定板图像 |
| **p** | 开始标定 | 使用已采集的数据进行标定计算 |
| **q** | 退出程序 | 退出程序（不会保存未标定的数据） |

### 4. 数据采集步骤

1. **准备标定板**
   - 将标定板放置在相机视野内
   - 确保标定板清晰可见，光线充足

2. **移动机器人**
   - 手动移动机器人到不同位置和姿态
   - 确保标定板在相机视野内
   - 建议采集 **15-30组** 数据，覆盖不同角度和位置

3. **采集数据（按 k 键）**
   - 每次按 `k` 键，程序会：
     - 获取当前机器人TCP位姿
     - 获取相机图像
     - 检测标定板角点
     - 如果检测成功，保存图像和位姿
     - 如果检测失败，提示"舍弃本次采集"

4. **重复步骤2-3**
   - 改变机器人位姿
   - 按 `k` 采集新数据
   - 重复直到采集足够的数据

### 5. 执行标定（按 p 键）

当采集了足够的数据后：

1. 按 `p` 键开始标定
2. 程序会：
   - 检查图像和位姿数量是否一致
   - 保存机器人位姿到文件
   - 执行相机内参标定
   - 执行手眼标定计算
   - 保存标定结果到JSON文件

3. 标定完成后会显示：
   ```
   标定完成！所有文件已保存到项目目录: /path/to/project1
     - 标定图像: /path/to/project1/images
     - 机器人位姿: /path/to/project1/project1_robotTcpPos.txt
     - 标定结果: /path/to/project1/conf/project1_CalibParams.json
   ```

## 输出文件说明

### 项目目录结构

```
calibrate_projects/
  {project_name}/
    ├── images/                                    # 标定图像目录
    │   ├── {project_name}_calib_image_0000.png
    │   ├── {project_name}_calib_image_0001.png
    │   └── ...
    ├── conf/                                      # 配置文件目录
    │   └── {project_name}_CalibParams.json       # 标定结果
    └── {project_name}_robotTcpPos.txt            # 机器人位姿数据
```

### 文件说明

#### 1. 标定图像 (`images/`)
- 文件名格式：`{project_name}_calib_image_{序号:04d}.png`
- 包含：采集的标定板图像
- 用途：用于标定计算和后续验证

#### 2. 机器人位姿文件 (`{project_name}_robotTcpPos.txt`)
- 格式：CSV格式，每行6个数值 `[x, y, z, rx, ry, rz]`
- 包含：每次采集时机器人的TCP位姿
- 单位：位置（mm），姿态（弧度）

#### 3. 标定结果文件 (`conf/{project_name}_CalibParams.json`)
- 格式：JSON格式
- 包含：
  ```json
  {
    "CameraMatrix": [[...]],           // 相机内参矩阵
    "CameraDistCoeffs": [[...]],       // 相机畸变系数
    "RotationMat": [[...]],            // 相机到基坐标系的旋转矩阵
    "TranslationMat": [[...]]          // 相机到基坐标系的平移向量
  }
  ```

## 数据采集建议

### 采集数量
- **最少**: 15组数据
- **推荐**: 20-30组数据
- **最佳**: 30-50组数据

### 位姿分布建议
- 覆盖不同的机器人姿态（俯仰、偏航、翻滚）
- 覆盖不同的工作空间位置
- 标定板在图像中的位置尽量分散
- 避免位姿过于相似

### 图像质量要求
- 标定板清晰可见
- 光线充足，避免反光
- 标定板平整，无遮挡
- 角点检测成功率 > 80%

## 常见问题

### Q1: 按 k 键后总是提示"舍弃本次采集"
**可能原因：**
- 标定板参数设置错误（行数、列数）
- 标定板不在相机视野内
- 光线不足或标定板模糊
- 标定板被遮挡

**解决方法：**
- 检查配置文件中的 `boardRowNums` 和 `boardCowNums` 是否正确
- 确保标定板完全在视野内且清晰可见
- 调整光线条件
- 检查标定板是否平整

### Q2: 标定时提示"图像和位姿数量不一致"
**原因：** 某些采集失败的数据被舍弃了

**解决方法：**
- 确保每次按 `k` 时都能成功检测到角点
- 重新采集数据，确保图像和位姿数量一致

### Q3: 无法连接到机器人
**可能原因：**
- 机器人IP地址错误
- 网络连接问题
- 机器人未上电或未使能

**解决方法：**
- 检查配置文件中的 `robotIP` 是否正确
- 使用 `ping` 命令测试网络连接
- 检查机器人状态，确保已上电并使能

### Q4: 无法获取相机图像
**可能原因：**
- 相机未连接
- 相机驱动问题
- pyorbbecsdk 模块未正确安装

**解决方法：**
- 检查相机USB连接
- 确认 pyorbbecsdk 模块已正确安装
- 检查相机权限设置

### Q5: 标定结果精度不高
**可能原因：**
- 采集数据量不足
- 位姿分布不够均匀
- 标定板参数设置错误

**解决方法：**
- 增加采集数据量（30组以上）
- 确保位姿覆盖不同角度和位置
- 检查标定板参数（特别是 `boardLength`）

## 标定结果验证

标定完成后，可以：

1. **检查标定结果文件**
   - 打开 `conf/{project_name}_CalibParams.json`
   - 检查各项参数是否合理

2. **使用标定结果**
   - 在其他程序中使用标定结果进行坐标转换
   - 参考 `visualDetect_ali.py` 的使用方式

3. **验证标定精度**
   - 使用标定结果进行像素到世界坐标的转换
   - 与实际测量值对比，评估标定精度

## 注意事项

1. ⚠️ **标定板参数必须准确**：错误的参数会导致标定失败或精度下降
2. ⚠️ **数据采集要充足**：至少15组，推荐20-30组
3. ⚠️ **位姿分布要均匀**：避免所有位姿过于相似
4. ⚠️ **标定板要平整**：弯曲或变形的标定板会影响精度
5. ⚠️ **光线要充足**：确保角点检测成功率高
6. ⚠️ **机器人要稳定**：采集时确保机器人已停止运动
